## Крок 2. Схема — 15 хв

Компоненти: **Arduino Uno R3**, **Ultrasonic Distance Sensor** — той, що з **чотирма** виводами,
**світлодіод**, **резистор 220 Ом**.

| Звідки | Куди |
|---|---|
| датчик VCC | 5V |
| датчик GND | GND |
| датчик TRIG | пін 9 |
| датчик ECHO | пін 10 |
| пін 13 | резистор 220 Ом → **довша** ніжка світлодіода (анод) |
| коротша ніжка світлодіода (катод) | GND |

✔ Усі дроти на місці, світлодіод — через резистор.

⚠️ Датчик із **трьома** виводами (PING))) — інший, з цим кодом не працює.

## Крок 3. Скетч і Serial Monitor — 10 хв

Кнопка **Code** → режим **Text** → стерти все й вставити:

```cpp
const int TRIG = 9;
const int ECHO = 10;
const int LED = 13;
const int PORIH = 15;                 // см — той самий, що в Gears

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

long vidstanSm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);           // імпульс 10 мкс — «крикнути»
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long mks = pulseIn(ECHO, HIGH, 30000);   // чекати відлуння не довше 30 мс
  if (mks == 0) return -1;                  // відлуння не повернулось
  return mks / 58;                          // 58 мкс ≈ 1 см туди й назад
}

void loop() {
  long d = vidstanSm();
  Serial.print("d = ");
  Serial.print(d);
  Serial.println(" cm");
  digitalWrite(LED, (d >= 0 && d < PORIH) ? HIGH : LOW);
  delay(100);
}
```

**Start Simulation**, потім **Serial Monitor** — кнопка внизу панелі коду.

✔ У Serial Monitor біжать рядки `d = … cm`.

## Крок 5. Той самий поріг у Gears — 20 хв

[Gears](https://gears.aposteriori.com.sg), світ **Grid**, стандартний робот (носом до стіни).
Вкладка **Python**, вставити:

```python
from ev3dev2.motor import MoveTank, OUTPUT_A, OUTPUT_B, SpeedPercent
from ev3dev2.sensor import INPUT_2
from ev3dev2.sensor.lego import UltrasonicSensor
import time

tank = MoveTank(OUTPUT_A, OUTPUT_B)
ultra = UltrasonicSensor(INPUT_2)
time.sleep(0.5)

PORIH = 15      # см — той самий поріг, що в Tinkercad
PAUZA = 0     # с між замірами

tank.on(SpeedPercent(30), SpeedPercent(30))
while ultra.distance_centimeters >= PORIH:
    time.sleep(PAUZA)
tank.off()
time.sleep(0.5)
print("пауза", PAUZA, "| зупинився за", round(ultra.distance_centimeters, 1), "см")
```

Три прогони з `PAUZA = 0`, потім три з `PAUZA = 0.3`. Між прогонами — кнопка скидання.

✔ Шість чисел «зупинився за … см».

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| Serial Monitor порожній | монітор не відкрито або немає `Serial.begin(9600)` | кнопка Serial Monitor унизу панелі коду |
| завжди `d = -1 cm` | TRIG і ECHO переплутані або датчик із трьома виводами | TRIG — пін 9, ECHO — пін 10; датчик із чотирма виводами |
| світлодіод не світить ніколи | обернена полярність | довша ніжка — до резистора, коротша — до GND |
| код не компілюється | лишився старий код або режим Blocks | Code → Text, стерти все, вставити заново |
| у Gears робот не зупиняється | робот не носом до стіни або датчик не на порту 2 | світ Grid, скидання; `UltrasonicSensor(INPUT_2)` |
| `git push` відхилено | немає прав або не той репозиторій | GitHub у браузері: тека → Add file → Upload files |
