## Крок 2. База коліс і поворот — 20 хв

Тут — у Gears, навіть якщо курсову робите у Webots.

[Gears](https://gears.aposteriori.com.sg), світ **Grid**, вкладка **Python**:

```python
from ev3dev2.motor import MoveTank, OUTPUT_A, OUTPUT_B, SpeedPercent
from ev3dev2.sensor import INPUT_3
from ev3dev2.sensor.lego import GyroSensor
import time

tank = MoveTank(OUTPUT_A, OUTPUT_B)
gyro = GyroSensor(INPUT_3)
time.sleep(0.5)

TRYVALIST = 1.0          # с — однаково для обох конфігурацій
kuty = []
for i in range(5):
    gyro.reset()
    time.sleep(0.3)
    tank.on(SpeedPercent(20), SpeedPercent(-20))     # поворот на місці праворуч
    time.sleep(TRYVALIST)
    tank.off()
    time.sleep(0.5)                                  # дочекатись зупинки
    kuty.append(gyro.angle)
    print("поворот", i + 1, ":", gyro.angle, "°")
print("середнє:", round(sum(kuty) / len(kuty), 1), "°")
```

1. ▶ — запишіть середнє. Це база **15,2 см** (стандартний робот).
2. Прогноз: якщо базу зробити **21,2 см**, кут за ту саму секунду буде більшим чи меншим? У скільки
   разів?
3. **Robot → Robot Configurator → Go to Configurator.** У списку зліва **Body** → повзунок `bodyWidth`
   з 14 на **20** (база = `bodyWidth` + 1,2 см = 21,2 см). **File → Save to file**.
4. Повернутись у симулятор: **Robot → Load from file** → збережений файл. ▶ — друге середнє.

✔ Два середні кути, і вони помітно різні. Числа залежать від кадрів комп'ютера — у сусіда будуть
трохи інші, а відношення — майже те саме.

## Крок 3. Зміна робота під рішення — 25 хв

Одна зміна, та, яку назвали в кроці 0.

**У Gears.** Robot Configurator → виділити **Body** → **Add** → потрібний компонент (наприклад,
`UltrasonicSensor` чи `ColorSensor`) → перетягнути або задати положення й поворот. Порт компонента
видно в дужках у списку — **саме його** пишете в коді, напр. `UltrasonicSensor(INPUT_…)`.
**File → Save to file** → `kursova/scena/robot.json` → у симуляторі **Robot → Load from file**.

**У Webots.** Відкрити свій світ, у дереві сцени розгорнути робота → поле **`turretSlot`** (у e-puck — місце
на верхній панелі) → кнопка **Add** (+) → **Base nodes → DistanceSensor**. Поля нового вузла:

| Поле | Значення | Навіщо |
|---|---|---|
| `name` | `"dalekomir"` | за цим ім'ям код знаходить датчик |
| `translation` | `0.03 0 0.005` | трохи вперед від центру турелі |
| `type` | `"sonar"` | промінь, а не ІЧ-відбиття |
| `lookupTable` | `0 0 0` і `1 1000 0` | 0–1 м → 0–1000: показ у міліметрах |

**File → Save World**.

✔ Новий компонент видно на роботі; світ або `robot.json` збережено в `kursova/scena/`.

## Крок 4. Використати зміну в коді — 15 хв

Датчик, який не читається програмою, — декорація. Додайте в автомат станів **одну умову**, яка
спирається на новий датчик і ухвалює рішення з кроку 0.

У Webots — `enable` обов'язковий:

```python
dalekomir = robot.getDevice("dalekomir")
dalekomir.enable(TIMESTEP)
# у циклі: dalekomir.getValue() — відстань у мм від датчика
```

| Webots: датчик показує 1000 і не змінюється | промінь іде повз перешкоду (вище чи вбік) | перевірити `translation` і висоту перешкоди |
