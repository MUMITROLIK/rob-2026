## Крок 4. Регулятор і три прогони — 35 хв

У коді є позначене місце:

```python
    # ─── крок 4: ваш регулятор — дві швидкості з BAZA, KP і pomylka ───
    v_l = BAZA
    v_p = BAZA
```

`pomylka > 0` означає: лінія праворуч. Напишіть дві швидкості так, як на темі 5:
базова швидкість плюс-мінус поправка, пропорційна помилці. Подумайте, яке колесо має
крутитися швидше, коли лінія праворуч.

<details>
<summary>Підказка, якщо застрягли на 10 хвилин</summary>

Щоб повернути праворуч, ліве колесо крутиться швидше за праве:
ліве — `BAZA` **плюс** поправка, праве — `BAZA` **мінус** поправка, поправка = `KP * pomylka`.

</details>

Три прогони по 60 с, `BAZA = 1.3`, міняєте тільки `KP`:

| Прогін | `KP` |
|---|---|
| 1 | 0.001 |
| 2 | 0.005 |
| 3 | 0.03 |

Після кожного запишіть рядок `ПІДСУМОК` (відсоток кроків без лінії і шлях) і що бачили:
зрізає повороти, тримає лінію, виляє, крутиться на місці.

✔ Три рядки в таблиці. Якщо при `KP = 0.005` робот тікає від лінії в перший же поворот — знак
поправки переплутано (див. «Якщо щось пішло не так»).

⚠️ Дивіться на **обидва** числа. 0 % без лінії при шляху 0,1 м — не ідеальний регулятор, а робот,
що крутиться на місці над лінією.

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| у консолі `python` не знайдено / контролер не стартує | Python не встановлено або не в PATH | крок 0; або **Tools → Preferences → General → Python command** — повний шлях до `python.exe` |
| `WARNING: … Skipped PROTO` | Webots не завантажив модель робота з мережі | перевірити інтернет, відкрити світ ще раз |
| робот не рухається взагалі | забули ▶ або контролер упав з помилкою | червоні рядки в консолі — номер рядка коду |
| робот тікає від лінії в першому повороті | переплутано знак поправки | поміняти `+` і `−` у двох рядках регулятора |
| робот крутиться на місці | `KP` завеликий: поправка більша за швидкість | зменшити `KP` |
| `The requested velocity … exceeds 'maxVelocity'` | швидкість понад 6,28 рад/с | Webots обріже до 6,28 сам; у коді вже є обмеження `MAX` |
| зміни в коді ніби не діють | не збережено файл або не скинуто симуляцію | зберегти → ⏮ Reset Simulation → ▶ |
| `git checkout shablon/main` — помилка | не з кореня репозиторію або забули `git fetch shablon` | `cd` у корінь, повторити три команди |
