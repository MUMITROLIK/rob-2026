## Крок 2. Карта — 30 хв

**Мета:** середовище, у якому місія має сенс. Обов'язково:

| Елемент | Навіщо |
|---|---|
| **стартова позиція** | інакше прогони незрівнянні |
| **зона успіху**, видна на екрані | щоб було видно на відео |
| щонайменше **одне місце, де можна помилитись** | розвилка, тупик, вузьке місце |
| записані розміри | потім у записку |

**Розмір поля.** За замовчуванням поле — лише **1 × 1 м**, і для більшості місій цього мало.
Розмір береться з картинки під роботом (100 пікселів = 10 см), а не з якихось «довжини й
ширини». У конструкторі клацніть **Ground** і виставте:

| Повзунок | Що робить | Приклад |
|---|---|---|
| `imageScale` | розтягує картинку: 1 піксель = N мм | 3 → поле **3 × 3 м** |
| `uScale` / `vScale` | тиражують картинку вздовж осі, масштаб малюнка зберігається | `uScale` 2 → поле **2 × 1 м** |

Максимум — 10 × 10 м. Свою картинку поля можна дати через `imageURL` (працює Imgur; більшість
інших хостингів браузер заблокує). Кнопка **Upload Image** у збережений файл карти **не
потрапляє** — для обміну картами вона не годиться.

Зберегти: **File → Save world to file** → `custom_world.json` → у `kursova/scena/`.

✔ Карта відповідає номеру середовища з картки; перша версія програми на ній, найімовірніше,
**провалиться** — і це правильно.

## Крок 3. Ускладнення в Gears — 15 хв

| Ускладнення з картки | Як зробити |
|---|---|
| 1 · Жорсткий ліміт часу | налаштування світу (Worlds → Select World → ваш світ): **Display Timer** і **At Timer End → Stop Robot** — програма зупиниться сама |
| 2 · Обмежений «заряд» | у програмі: лічильник обертів коліс (`tank.left_motor.position`) — перевищив ліміт — стоп |
| 3 · Датчик шумить | у програмі: `v = color.reflected_light_intensity + random.randint(-8, 8)` (і `import random`) |
| 4 · Стартова позиція невідома | налаштування світу: **Starting Position (x, y, z)** і **Starting Rotation** — кожен прогін інші |
| 5 · Заборонені зони | кольорова зона на підлозі карти; датчик кольору бачить її як інше число (робота 4) |
| 6 · Карти наперед немає | у коді жодних координат чи «проїхати 40 см, повернути» |
| обмежена видимість (середовище 6) | у програмі: якщо `ultra.distance_centimeters > 30`, вважати, що попереду нічого немає |

⚠️ GPS — тільки лінійка для замірів. Місія через GPS не зараховується як автономна навігація.

✔ Ваше ускладнення **відчутне**: якщо ліміт часу — карта не проходиться «з запасом утричі».

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| сцена не завантажується в конструкторі | файл не з World Builder | File → New World і зібрати заново; зберігати тільки через Save world to file |
| поле замале, об'єкти не вміщаються | поле за замовчуванням 1 × 1 м | **Ground** → `imageScale` (3 → 3 × 3 м) або `uScale` / `vScale` для прямокутного поля |
| змінив «length» / «width» у файлі — нічого не сталось | у світі Custom ці параметри не працюють | розмір задається тільки через `imageScale` / `uScale` / `vScale` |
| картинка поля зникла після збереження | завантажена через **Upload Image** | `imageURL` (Imgur) або лишити стандартну картинку |
| робот стартує в стіні або поза полем | стартова позиція збита | налаштування світу → Starting Position |
| програма зупиняється «сама» посеред прогону | спрацював таймер світу | це ваше ускладнення; запишіть як провал |
| з першого разу пройшло три з трьох | задачі на карті немає | ускладнити: вужче, далі, ще одна розвилка |
| у критерії немає числа | «добре», «швидко», «впевнено» | переписати за формулою |
