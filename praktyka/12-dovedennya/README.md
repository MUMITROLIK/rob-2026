## Крок 0. Від старту до критерію — 20 хв

Робот має хоч раз пройти **всю** місію: від старту до вашого критерію успіху. Якщо зараз розсипається —
три типові затори нижче.

| Затор | Ознака | Ліки |
|---|---|---|
| частини працюють, разом — ні | кожен стан окремо ок, послідовність розсипається | дії **при вході в стан** — окремою функцією: скинути гіроскоп, лічильник, таймер |
| працює раз із п'яти | залежить від точного часу чи положення | записати, **у якому стані** ламається, — крок 2 |
| робот застряг і стоїть | стан чекає події, яка не настає | **таймаут** у кожному стані → стан `VIDNOVLENNYA`: назад, розворот, спроба ще |

<details>
<summary>Каркас: вхід у стан і таймаут</summary>

```python
MAX_CHAS = {"VPERED": 8, "POVOROT": 4, "VIDNOVLENNYA": 3}   # с — ваші числа

def uviyty(novyi):
    global stan, t_vhodu
    if novyi == "POVOROT":
        gyro.reset()            # усе, що треба скинути при вході
    stan = novyi
    t_vhodu = time.time()

# у головному циклі, у кожному стані:
if time.time() - t_vhodu > MAX_CHAS[stan]:
    uviyty("VIDNOVLENNYA")
```

</details>

✔ Хоч один прогін від старту до критерію.

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| місія не доходить до кінця жодного разу | місія завелика для чотирьох тижнів | **спростити**: прибрати одну частину місії — скажіть мені сьогодні |
| робот «зависає» в одному стані | немає таймауту | каркас кроку 0 |
| поворот щоразу інший | гіроскоп не скинуто при вході в стан | `gyro.reset()` у `uviyty()` |
| п'ять прогонів дають однаковий провал | детермінована помилка, не випадковість | це добре: знайдено причину — крок 3 |
| Gears: програма зупинилась посеред прогону | спрацював таймер світу (ваше ускладнення) | записати як провал |
| Webots: після зміни коду поведінка та сама | не збережено або не скинуто симуляцію | зберегти → ⏮ Reset → ▶ |
