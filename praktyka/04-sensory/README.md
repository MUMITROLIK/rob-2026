## Крок 0. Світ і каркас — 5 хв

1. Датчик під місію — **лінії** (колір), **ультразвуковий** або **гіроскоп**.
2. Світ для замірів: датчик лінії — **Worlds → Select World → Line Following
   Challenges**, траса *Simple Curves* (робот стартує на лінії); ультразвук —
   світ **Grid** (по краях поля стіни).
3. Вкладка **Python**, вставити каркас:

```python
from ev3dev2.motor import MoveTank, OUTPUT_A, OUTPUT_B, SpeedPercent
from ev3dev2.sensor import INPUT_1, INPUT_2
from ev3dev2.sensor.lego import ColorSensor, UltrasonicSensor
import time

tank = MoveTank(OUTPUT_A, OUTPUT_B)
color = ColorSensor(INPUT_1)          # ⚠️ у Gears порт обов'язковий
ultra = UltrasonicSensor(INPUT_2)
time.sleep(0.5)

tank.on(SpeedPercent(10), SpeedPercent(10))
for i in range(1, 21):
    print(i, color.reflected_light_intensity, round(ultra.distance_centimeters, 1))
    time.sleep(0.5)
tank.off()
```

4. Вкладка **Simulator** → ▶. Консоль — унизу (стрілка `^`, якщо згорнута).

✔ У консолі 20 рядків: номер, показ кольору, відстань.

## ⚠️ Чим Gears відрізняється від справжнього датчика

| Що | У Gears | Що з цим робити |
|---|---|---|
| **шум** | немає: нерухомий датчик щоразу дає те саме число | заміри робити **в русі**; якщо потрібен шум — додати самим: `v = color.reflected_light_intensity + random.randint(-8, 8)` (і `import random`) |
| **біле поле траси** | не одне число, а цілий діапазон — залежить від того, куди повернутий робот | поріг не ставити впритул до білого |
| **ультразвук і коса стіна** | під великим кутом стіна «зникає» — датчик бачить щось далі | з якого кута — ⭐1 |
| **GPS** | точні координати | тільки для налагодження; місія через GPS не зараховується |

⭐ Ускладнення № 3 з матриці варіантів — «датчик шумить сильніше за норму» — у Gears
робиться саме так: шум додається в програмі.

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| `TypeError: No color sensor connected to null` | датчик без порту | `ColorSensor(INPUT_1)`, `UltrasonicSensor(INPUT_2)` |
| усі 20 чисел однакові | робот стоїть або їде тією самою поверхнею | їхати через межу; змінити старт чи напрямок |
| відстань завжди `255` | попереду нічого немає або стіна під великим кутом | світ Grid, робот носом до стіни |
| робот виїхав за поле | 20 × 0,5 с на 10 % — задовго для вашого старту | менше показів або повільніше |
| сцена не завантажується | файл не з World Builder або зіпсований | зберегти ще раз: File → Save world to file |
| `git push` відхилено | немає прав або не той репозиторій | GitHub у браузері: тека → Add file → Upload files |
