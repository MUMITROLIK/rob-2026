## Крок 0. Каркас — 5 хв

1. Відкрити [Gears](https://gears.aposteriori.com.sg). Світ і робот — ті, що
   відкриваються самі: світ **Grid**, робот **Single Sensor Line Follower**.
   Якщо міняли — **Worlds → Select World → Grid** і **Robot → Select Robot**.
2. Вкладка **Python**, стерти все й вставити:

```python
from ev3dev2.motor import MoveTank, OUTPUT_A, OUTPUT_B, SpeedPercent
from ev3dev2.sensor import INPUT_3
from ev3dev2.sensor.lego import GyroSensor
import time

tank = MoveTank(OUTPUT_A, OUTPUT_B)   # A — ліве колесо, B — праве
gyro = GyroSensor(INPUT_3)            # ⚠️ у Gears порт обов'язковий
time.sleep(0.5)

print("гіроскоп:", gyro.angle)
```

3. Вкладка **Simulator** → ▶. Консоль — унизу екрана симулятора
   (якщо згорнута — стрілка `^` праворуч унизу).

✔ У консолі: `гіроскоп: 0`

## Крок 2. Поворот «на час», 10 разів — 20 хв

**Мета:** робот десять разів поспіль повертається праворуч «на час», а
програма після кожного повороту друкує, на скільки він **справді** повернувся.

<details>
<summary>Підказка — код циклу, дописати під каркас</summary>

```python
poperednii = gyro.angle
for i in range(1, 11):
    tank.on_for_seconds(SpeedPercent(20), SpeedPercent(-20), 1.0)
    time.sleep(0.5)                  # дати роботу заспокоїтись
    teper = gyro.angle
    print(i, teper - poperednii)     # кут САМЕ ЦЬОГО повороту
    poperednii = teper
```

</details>

Перенести десять чисел у стовпчик «на час» таблиці в `zvit.md` (заготовка нижче).

✔ Десять чисел, і вони **не 90 і не однакові**.

⚠️ Записуйте різницю з попереднім показом, а не сам `gyro.angle`: після
четвертого повороту він уже під 300.

## Крок 3. Середнє, розкид, систематична похибка — 15 хв

| Що | Як порахувати | Що це означає |
|---|---|---|
| **середнє** | сума десяти / 10 | куди робот «тягне» щоразу |
| **систематична похибка** | середнє − 90 | повторюється → її **можна компенсувати** |
| **розкид** | найбільше − найменше | випадкова частина → **не компенсується** |

✔ Під стовпчиком «на час» — три числа. Порівняйте середнє зі своїм прогнозом.

## Крок 4. Поворот «по гіроскопу», 10 разів — 25 хв

**Мета:** робот повертається, **поки гіроскоп не покаже 90°**. Десять разів,
перед кожним поворотом гіроскоп обнуляється. Порахувати те саме: середнє й розкид.

<details>
<summary>Підказка — код циклу, замінити цикл кроку 2</summary>

```python
for i in range(1, 11):
    gyro.reset()                     # обнулити перед кожним поворотом
    tank.on(SpeedPercent(20), SpeedPercent(-20))
    while gyro.angle < 90:           # праворуч — кут зростає
        pass
    tank.off()
    time.sleep(0.5)
    print(i, gyro.angle)
```

</details>

✔ Числа ближчі до 90, але **більші** за 90, а розкид менший, ніж у кроці 2.

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| `TypeError: No gyro sensor connected to null` | датчик створено без порту | `GyroSensor(INPUT_3)` і `from ev3dev2.sensor import INPUT_3` |
| `No gyro sensor connected to in3` | вибрано іншого робота | **Robot → Select Robot** → Single Sensor Line Follower |
| консоль порожня | запущено не з вкладки Simulator або консоль згорнута | вкладка **Simulator**, ▶, стрілка `^` унизу |
| кут завжди `0`, робот стоїть | програма впала до руху — дивіться червоний рядок у консолі | виправити помилку, ▶ ще раз |
| у кроці 4 робот крутиться без кінця | крутиться **ліворуч**, кут від'ємний | швидкості `20, -20` (саме в такому порядку) |
| числа 90, 180, 270… у кроці 2 | записуєте `gyro.angle`, а не різницю | `teper - poperednii` |
| `IndentationError` | змішані пробіли й табуляція | відступи — 4 пробіли |
| у вас не такі числа, як у сусіда | так і має бути | це тема розбору в третій парі |

## ⭐ Драбина — хто закінчив раніше

Беріть по черзі, не чекайте. Кожен щабель — рядок у `zvit.md`: що зробили,
число, висновок.

| # | Завдання | Хв |
|---|---|---|
| ⭐1 | **Швидкість.** Поворот по гіроскопу на 10 % і на 40 %, по 5 разів. Спершу прогноз: де перекрут більший і чому? | 10 |
| ⭐2 | **Точний поворот.** Дві швидкості: 30 % до 70°, потім 5 % до 90°. Мета — рівно 90° у п'яти поворотах із п'яти | 15 |
| ⭐3 | **Кут з коліс.** `tank.left_motor.position` — градуси обертання колеса. Шлях колеса $s = \frac{\text{градуси}}{360}\cdot\pi\cdot 5{,}6$ см, кут $\Delta\theta = \frac{s_L - s_R}{b}$, $b = 15{,}2$ см. Порівняйте з гіроскопом і знайдіть, за якої $b$ числа збігаються. Чому вона не 15,2? | 20 |
| ⭐⭐4 | **Справжня задача — повернутися на базу.** Робот проїжджає 40 см → повертає праворуч на 90° → 30 см → праворуч ще на 135° → 25 см, увесь час рахуючи свої $(x, y)$ лише з коліс і гіроскопа. Потім **сам** розвертається до старту й доїжджає. Промах вимірюєте GPS (`GPSSensor(INPUT_4)`, `gps.x`, `gps.y`, у см) — але в розрахунку руху GPS **не використовувати**. Мета — промах ≤ 3 см | 40+ |

⭐⭐4 — це місія № 11 з матриці варіантів у мініатюрі й шматок теми 15.

## Трек П
