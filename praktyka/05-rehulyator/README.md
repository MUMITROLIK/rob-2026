## Крок 0. Траса й каркас — 10 хв

**Світ:** Worlds → Select World → **Line Following Challenges**, траса **Simple Curves**.
Це не коло, а смуга з поворотами: робот стартує на лінії, і міряємо **час до кінця траси**.

```python
from ev3dev2.motor import MoveTank, OUTPUT_A, OUTPUT_B, SpeedPercent
from ev3dev2.sensor import INPUT_1, INPUT_4
from ev3dev2.sensor.lego import ColorSensor
from ev3dev2.sensor.virtual import GPSSensor
import time

tank = MoveTank(OUTPUT_A, OUTPUT_B)
color = ColorSensor(INPUT_1)          # ⚠️ у Gears порт обов'язковий
gps = GPSSensor(INPUT_4)              # лише щоб зупинити секундомір на фініші
time.sleep(0.5)

PORIH = 50                            # з роботи 4: біле 100, чорне 1


def obmezhyty(v):
    """SpeedPercent поза ±100 у Gears падає з ValueError."""
    return max(-100, min(100, v))


pochatok = time.time()
while time.time() - pochatok < 120 and gps.y < 85:
    v = color.reflected_light_intensity
    # ↓↓↓ сюди — код кроку 2, 3 або 4 ↓↓↓

tank.off()
print("час до кінця траси: %.1f с" % (time.time() - pochatok))
```

⚠️ GPS тут — лише секундомір. У самому керуванні його **не використовувати**.

✔ Каркас без коду в циклі одразу друкує час (робот стоїть) — значить, усе підключено.

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| `TypeError: No color sensor connected to null` | датчик без порту | `ColorSensor(INPUT_1)` |
| `ValueError: Value must be between -100 and 100` | швидкість вийшла за 100 % | загорнути в `obmezhyty(...)` |
| робот одразу з'їжджає з лінії й їде геть | `Kp` замалий або знак навпаки | перевірити: `e = PORIH - v`, ліве `BAZA - korekciya` |
| робот крутиться на місці біля старту | `Kp` завеликий | зменшити вдвічі |
| цикл не закінчується | робот загубив лінію й не дійде до фінішу | зупинити ■, записати «не доїхав» — це теж результат |

## Трек П

**D-складова** — у циклі замість кроку 3:

```python
    e = PORIH - v
    d = e - e_pop
    korekciya = Kp * e + Kd * d
    e_pop = e
    tank.on(SpeedPercent(obmezhyty(BAZA - korekciya)),
            SpeedPercent(obmezhyty(BAZA + korekciya)))
```

(перед циклом: `Kd = 1.0` і `e_pop = 0`). Таблиця Kp × Kd щонайменше 3 × 3: час і чи
розгойдується. Чесна відповідь «Д тут нічого не дала» — теж відповідь, якщо спирається на числа.

⚠️ **I-складову не беремо.** Вона легко псує все, якщо не обмежити накопичення.
