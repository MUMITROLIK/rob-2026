## Крок 0. Каркас — 10 хв

Робот їде до перешкоди, сповільнюється, зупиняється й розвертається. У світі **Grid** працює як є.

```python
from ev3dev2.motor import MoveTank, OUTPUT_A, OUTPUT_B, SpeedPercent
from ev3dev2.sensor import INPUT_2, INPUT_3
from ev3dev2.sensor.lego import UltrasonicSensor, GyroSensor
import time

tank = MoveTank(OUTPUT_A, OUTPUT_B)
ultra = UltrasonicSensor(INPUT_2)     # ⚠️ у Gears порт обов'язковий
gyro = GyroSensor(INPUT_3)
time.sleep(0.5)

stan = "poshuk"
vkhid = time.time()                   # коли увійшли в поточний стан


def perekhid(novyi):
    """Єдине місце, де змінюється стан: друк і дії при вході."""
    global stan, vkhid
    print(f"{stan} -> {novyi}")
    stan = novyi
    vkhid = time.time()
    if novyi == "rozvorot":
        gyro.reset()                  # скинути гіроскоп при вході в поворот


while stan != "gotovo":
    d = ultra.distance_centimeters

    if stan == "poshuk":              # їдемо вперед, дивимось уперед
        tank.on(SpeedPercent(30), SpeedPercent(30))
        if d < 45:
            perekhid("pidhid")

    elif stan == "pidhid":            # наближаємось повільно
        tank.on(SpeedPercent(10), SpeedPercent(10))
        if d < 15:
            perekhid("rozvorot")

    elif stan == "rozvorot":          # розвертаємось на місці
        tank.on(SpeedPercent(20), SpeedPercent(-20))
        if gyro.angle >= 180:
            tank.off()
            perekhid("gotovo")

    if time.time() - vkhid > 20:      # таймаут: стан без виходу
        print("таймаут у стані", stan)
        tank.off()
        break
```

✔ У консолі три рядки: `poshuk -> pidhid`, `pidhid -> rozvorot`, `rozvorot -> gotovo`.

⭐ У кожен момент робот рівно в одному стані, стан змінюється тільки в `perekhid()`, і немає
жодного вкладеного `if` глибше двох рівнів. У цьому вся ідея.

## Якщо щось пішло не так

| Що бачите | Причина | Що зробити |
|---|---|---|
| `TypeError: No ultrasonic sensor connected to null` | датчик без порту | `UltrasonicSensor(INPUT_2)`, `GyroSensor(INPUT_3)` |
| останній рядок у консолі — `poshuk -> pidhid`, і більше нічого | застряг у стані: умова переходу не виконується | подивитись на умову цього стану; для того й друк |
| `таймаут у стані …` | стан без виходу | це не помилка таймауту — це він вас урятував; виправити умову |
| розворот не закінчується | гіроскоп не скинули або крутиться ліворуч (кут від'ємний) | `gyro.reset()` при вході; швидкості `20, -20` |
| стан міняється щоцикла туди-сюди | умова на межі — тремтіння | гістерезис із роботи 4: два пороги |
| сцена не завантажується | файл не з World Builder | Worlds → World Builder → File → Save world to file |
